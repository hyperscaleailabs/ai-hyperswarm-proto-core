## Direction (where we are going)
- **G1** - Learn from the top-10 AI swarm / multi-agent projects: Continuously extract and adapt best practices from the reference set below - not just from source code, but from commit history, CI/CD pipelines, issue history, and agent/harness design. Every improvement should trace back to something observed in the field.
- **G2** - Stay auditable and traceable end to end: Every change is a PR; every PR is linked to a ticket, records which model produced it, and carries a lesson learned (pass or fail).
- **G3** - Grow the knowledge base: Turn lessons into durable articles and periodic whitepapers, indexed as Maps of Content (MOCs), kept Obsidian-ready.
- **G4** - Improve the harness itself: Sharpen orchestration, model-selection, CI signal, and safety guardrails so the loop is faster, cheaper (in quota), and safer over time.

Review rhythm: scheduled cycle -> whitepaper + brief -> architect runs
`/review-next` -> feedback becomes ADRs + tickets -> PR merged -> next block.
