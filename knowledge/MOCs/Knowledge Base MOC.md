# Knowledge Base MOC

The living memory of **ai-hyperswarm-proto-core**. Open this repo as an Obsidian
vault and use the graph view to explore how lessons connect.

## Maps
- [[Lessons MOC]] - 31 lesson(s)
- [[Whitepapers MOC]] - 9 whitepaper(s)
- [[Articles MOC]] - 24 article(s)

## How this is maintained
- Each PR the [[hsai]] loop opens contributes exactly one lesson.
- Every 10 lessons, a whitepaper synthesizes the themes.
- Each whitepaper is rewritten as one article per persona - see [[Articles MOC]].
- These MOCs are regenerated by `hsai reindex` after each iteration, and
  `hsai audit` fails loudly if they ever drift from what is on disk.
